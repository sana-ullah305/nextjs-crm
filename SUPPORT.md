# Support

Thanks for using nextjs-crm! Here's where to get help.

## 💬 Questions and discussions

- [GitHub Discussions](https://github.com/sana-ullah305/nextjs-crm/discussions) —
  the best place for questions, setup help, and ideas.

## 🐛 Bugs and feature requests

- [Open a bug report](https://github.com/sana-ullah305/nextjs-crm/issues/new?template=bug_report.md)
- [Open a feature request](https://github.com/sana-ullah305/nextjs-crm/issues/new?template=feature_request.md)

Search [existing issues](https://github.com/sana-ullah305/nextjs-crm/issues)
first — duplicates help no one.

## 🔒 Security issues

Do **not** use issues for security vulnerabilities — see
[SECURITY.md](SECURITY.md).

## 🚀 Self-service

- [README](README.md) — quick start, scripts, deployment
- [docs/](docs/) — architecture, database schema, API reference,
  implementation plan, security
- `npm run typecheck && npm run lint && npm test` — verify your setup
